# Start the final campus demo

```powershell
.\Demo.ps1 -OpenBrowser
```

Open http://127.0.0.1:7861/presenter. Campus-tuned search starts on; use the on/off toggle for the base model. The gallery can be browsed while Giant warms up.

Base fallback: ` .\Demo.ps1 -TextProfile base -OpenBrowser `. Self-contained backup: open `Gallery_Preview.html`.

See [QUICK_DEMO.md](QUICK_DEMO.md) for exact indexing, both-profile prepared query rebuild, offline, evaluation and cleanup commands. See [DEMO_QUERIES.md](DEMO_QUERIES.md) for tested demo searches and known wrong-place results.
